# ConsultaAI

SaaS de consultas com arquitetura preparada para provedores autorizados.

## Stack
Next.js App Router, TypeScript, Supabase Auth/Postgres/RLS e Vercel.

## Segurança
O projeto não usa bases vazadas ou fontes não autorizadas. O modo inicial registra consultas sintéticas/demonstrativas. Integrações reais devem usar provedores autorizados e credenciais armazenadas somente no servidor.
